기존의 반복적이고 예측 가능한 작업은 디지털 기술로 대체되고, 창의적이고 가치 있는 업무에 집중할 수 있게 됨

핵심 개념 정의
개념정의
정보의미 있고 가치 있는 데이터로서 의사 결정을 지원. 보호해야 할 정보·공유해야 할 정보·공유할 수 있는 정보 등으로 구분
정보 보호정보가 불법적으로 유출·훼손·파괴·변조·접근·기록되는 등의 여러 가지 위협으로부터 보호하기 위한 모든 행위
정보 공유정보를 여러 사람이 함께 사용하며, 사용 권한에 따라 삽입·수정·삭제 등을 하는 것
개인 정보
특정 개인을 식별할 수 있는 모든 정보
이름, 주민등록번호, 영상 등으로 알아볼 수 있는 개인에 관한 정보
다른 정보와 쉽게 결합하여 알아볼 수 있는 개인 정보까지 포함
📝 저작물과 저작권
저작물이란?
시·소설·음악·미술·영화·컴퓨터 프로그램과 같이 사람의 사상이나 감정을 표현한 창작물
창작자는 저작물에 대한 저작권을 가짐
저작권 보호 목적: 저작자가 창작 활동에 전념할 수 있는 동기를 부여하여 더 좋은 작품을 만들 수 있도록 하기 위함
CCL (저작물 이용 허락 표시)
저작권자가 사용 조건을 미리 제시해 사용자가 저작권자에게 따로 허락을 구하지 않고도 창작물을 사용할 수 있게 한 일종의 오픈 라이선스
소프트웨어 저작권 — 종류별 비교
종류설명특징
상용 소프트웨어일정 금액을 받고 이용자에게 판매하는 소프트웨어무단 복제·배포 불가
공개 소프트웨어무료로 배포하는 소프트웨어배포·복제 비교적 자유, 소스 코드 미공개, 무단 수정 대부분 금지
오픈 소스 소프트웨어완성된 소프트웨어의 사용·배포가 자유롭고 소스 코드 전체를 공개소스 코드 활용하여 다른 프로그램 제작 허용, 다양한 버전 존재
소프트웨어 라이선스
저작권 소유자로부터 일정한 사용권을 허가받는 것 (저작권 취득과는 다름)
라이선스별로 저작권의 일부분을 허용하며 그 정도가 각각 다름

사용 대상에 따른 분류

최종 사용자 라이선스, 공공 기관 라이선스, 교육 기관 라이선스, 기업 라이선스 등

사용 기간에 따른 분류

영구 라이선스, 기간제 라이선스, 한시적 라이선스

기타 분류

패키지·볼륨·서비스·번들·OEM 라이선스 등

🛡️ 정보 보안 실천 방법
실천 항목방법

개인 암호 설정비밀번호, 얼굴 인식, 지문 인식, PIN번호 등 다양하게 설정
클라우드 2단계 인증스마트폰 기기로 로그인 시 해당 기기에 인증 알림을 발송하고 허용해야만 로그인되는 이중 보안 서비스
어플리케이션 관리출처 불명 앱 사용 금지, 정기적 소프트웨어 업데이트, 앱 설치 시 필수 권한만 허용
웹 브라우저 관리최신 버전 사용, 보안 사이트는 주소창에 https로 시작 + 자물쇠 아이콘 확인
💡 https와 자물쇠 아이콘 — 보안이 설정된 웹 사이트의 주소창은 'https://'로 시작하며 자물쇠 모양 아이콘이 표시됨

⚠️ 사이버 폭력
사이버 폭력이란?
사이버 공간에서 타인에게 피해를 입히는 행위
악성 댓글, 허위 사실 유포, 신상 털기, 사이버 성폭력, 사이버 스토킹 등

⚡ 발생 원인

  • 익명성으로 인한 죄책감 결여
  • 여러 개의 자아로 인한 자기 통제력 약화
  • 비대면성으로 인한 타인 감정 조망 능력 약화

🛡 예방 대책

  • 유형별 처벌 규정 존재 (사후 처방적)
  • 처벌은 근본적 해결책이 될 수 없음
  • 사이버 공간 사용자들의 윤리 의식의 변화만이 근본적 해결책
🚨 사이버 범죄
사이버 범죄의 특징
컴퓨터·통신·인터넷 등을 악용하여 사이버 공간에서 행하는 범죄

주요 특징

  • 익명성과 비대면성
  • 빠른 확산 및 피해 추정의 어려움
  • 지능적이고 고도의 전문 지식 악용
  • 범죄의 발견·증명 및 입증 어려움
  • 범죄성에 대한 인식 희박 및 결여

사이버 범죄 유형 3가지

  • 피싱 개인 정보(private data) + 낚시(fishing) 합성어. 위장 홈페이지나 이벤트 미끼로 개인 정보 탈취
  • 파밍 피싱(phishing) + 조작(farming) 합성어. 악성 코드로 PC를 조작해 가짜 사이트로 유도 후 금융 정보 탈취
  • 스미싱 문자(SMS) + 피싱(phishing) 합성어. 문자 메시지 URL 클릭 시 악성 코드 설치 → 소액 결제 또는 개인 금융 정보 탈취
⚠️ 피싱·파밍·스미싱 공통점: 모두 개인 정보 또는 금융 정보를 탈취하는 사이버 범죄. 합성어 어원을 함께 암기!

🔍 1-1 문제 분석
문제 분석이란?
문제: 우리가 해결해야 할 구체적이고 명확한 요구 사항
문제를 명확하게 이해하고 주어진 문제 상태·요구 사항·제약 조건을 정의하기 위해 수행하는 과정
✂️ 1-2 추상화와 문제 분해
추상화(Abstraction)
복잡한 문제를 단순화하는 것
문제를 작은 단위로 분해한 후 불필요한 요소는 제거하고 꼭 필요한 핵심 요소만 추출하는 것
문제 분해(Decomposition)
복잡한 문제를 해결하기 쉽게 작은 문제로 나누는 과정
문제 사이의 관계나 순서에 유의하여 작은 문제로 분해하여 먼저 해결하고, 그 결과를 종합하면 문제 전체를 해결할 방법을 찾을 수 있음
핵심 요소 추출
추상화의 가장 중요한 단계
문제 해결과 관련 없는 불필요한 요소를 제거하고 꼭 필요한 핵심 요소를 추출하는 과정
여러 정보와 사실을 구분하기 위한 기준이 있어야 하며, 그 기준은 문제 해결의 목적에 따라 달라질 수 있음

📊 Ⅲ-1-3 모델링  —  표(Table) · 트리(Tree)
🗂️ 모델링이란?
분해한 문제에서 추출한 핵심 요소들을 이해하기 쉽게 표·트리·그래프 등으로 단순화하거나 구조화하는 과정
데이터 간의 관계나 흐름을 쉽게 이해할 수 있어 문제를 효율적으로 해결하는 데 도움이 됨
📋 표 (Table)
데이터를 가로축(행)과 세로축(열)으로 나누어 표현하는 구조
주어진 조건들을 비교·평가하거나 복잡한 문제들을 보기 쉽게 정리할 수 있음
📝 표는 가장 직관적인 모델링 방법으로, 여러 항목을 행·열로 정렬하여 한눈에 비교할 때 사용
🌳 트리 (Tree)
트리란?
데이터 사이의 관계를 계층적으로 표현하기에 적합한 구조
상위 노드에서 하위 노드로만 간선이 존재하고, 노드 간 사이클(순환)은 허용하지 않음
트리 용어 완전 정리
용어정의
노드 (Node)데이터 항목을 나타내는 것으로 도형 상의 정점을 의미
간선 (Edge)데이터의 흐름이나 관계를 선으로 나타낸 것
루트 노드상위 노드가 없는 최상위 노드
부모 노드하위 노드를 가지고 있는 상위 노드
자식 노드상위 노드를 가지고 있는 하위 노드
형제 노드같은 부모 노드에 속하는 같은 레벨의 노드
서브 트리트리에서 루트 노드를 제거했을 때 발생하는 트리 (트리의 부분 집합)
차수각 노드가 가진 가지(자식 노드)의 개수. 트리를 구성하는 노드의 최대 차수가 트리의 차수
레벨루트 노드부터 현재 노드까지의 경로를 표시했을 때 그 거리. 루트와 가장 먼 노드의 레벨이 트리의 높이(깊이)
경로트리 구조 내에서 한 노드부터 다른 노드까지 이동하는 동안 거치는 노드와 간선의 집합
사이클특정 노드에서 출발하여 간선과 노드를 지나 다시 처음 노드로 돌아오는 순환 구조. 트리는 사이클 허용 안 함!
트리 시각화 예시
A ← 루트 노드 (레벨 0) ├── B ← A의 자식, C의 형제 (레벨 1) │ ├── D (레벨 2, 차수 0 = 리프 노드) │ └── E (레벨 2) └── C ← A의 자식, B의 형제 (레벨 1) └── F (레벨 2)

A의 차수

자식 노드 B, C → 차수 = 2

트리의 높이

루트(A)부터 가장 먼 D,E,F까지 → 높이 = 2

형제 노드

B와 C (같은 부모 A, 같은 레벨 1)

예: A — B (A↔B 양방향)

방향 그래프

노드 사이를 연결하는 간선에서 방향이 존재하는 그래프

구조에 따른 분류

완전 그래프

그래프를 구성하는 모든 노드 사이에 간선이 존재하는 그래프

그래프의 모든 정점을 연결하는 간선의 집합

사이클 (Cycle)

⚙️ Ⅲ. 알고리즘과 프로그래밍 › 2-1 알고리즘의 이해
📌 알고리즘이란?
문제 해결을 위한 방법이나 절차
문제 해결을 위해 단계별로 정의된 규칙의 집합
생활 속 문제 해결을 위해 다양한 알고리즘을 이용
알고리즘 설계: 문제 해결을 위한 구체적인 방법을 기술하는 것
문제의 특성과 요구사항을 고려하여 다양한 구조로 설계할 수 있음
🔀 알고리즘 제어 구조 3가지

① 순차 구조

순서대로 명령을 실행한다

위에서 아래로 차례대로 실행. 가장 기본적인 구조

② 선택 구조

주어진 조건에 따라 실행하는 명령이나 순서가 달라진다

조건이 참/거짓이냐에 따라 다른 경로 실행

③ 반복 구조

주어진 조건에 따라 특정 명령을 반복적으로 실행한다

조건이 참인 동안 특정 명령을 반복

📝 3가지 제어 구조는 모든 알고리즘의 기본 골격. 순차·선택·반복 세 가지를 조합하면 어떤 문제도 표현 가능!
📝 알고리즘 표현 방법 3가지
표현 방법설명특징
자연어특정한 형식 없이 말이나 글로 표현하는 방법누구나 이해하기 쉬움, 모호한 표현 발생 가능
의사 코드프로그램 코드를 흉내 내어 알고리즘을 표현하는 방법실제 코드와 유사, 프로그래밍 언어에 독립적
순서도정해진 기호를 이용하여 알고리즘을 표현시각적으로 흐름 파악이 용이, 기호별 의미 약속
🔢 Ⅲ-2-2 정렬 알고리즘
⚡ 알고리즘의 효율성
알고리즘은 문제 해결의 효율성을 결정하는 중요한 요소
효율적인 알고리즘은 적은 자원으로 더 빠르게 결과를 도출해냄
알고리즘 구조에 따라 수행 시간에 차이가 발생하기 때문에 효율적인 알고리즘을 설계하고 선택해야 함

✅ 효율적인 알고리즘의 조건

  • 작업량이 적고 수행 시간이 짧다
  • 기억 장소(메모리)의 사용량이 적다

📊 정렬이란?

수많은 데이터를 특정 기준에 따라 순서대로 나열하는 것

오름차순 작은→큰 순서

내림차순 큰→작은 순서

📋 5가지 정렬 알고리즘
① 선택 정렬 (Selection Sort)
아직 정렬되지 않은 임의의 데이터 중 위치에 알맞은 값을 선택하여 이동하는 정렬 방법

동작 원리

정렬되지 않은 부분에서 최솟값을 찾아 정렬된 부분의 맨 뒤와 교환 반복

예: [5, 3, 1, 4, 2] → 최솟값 1 선택 → [1, 3, 5, 4, 2] → 최솟값 2 선택 → ...

② 삽입 정렬 (Insertion Sort)
아직 정렬되지 않은 임의의 데이터를 이미 정렬된 부분의 적절한 위치에 삽입해 가는 정렬 방법

동작 원리

현재 요소를 이미 정렬된 왼쪽 부분과 비교하며 알맞은 위치를 찾아 삽입

예: [5, 3, 1, 4, 2] → 3을 정렬 부분에 삽입 → [3, 5, 1, 4, 2] → ...

③ 버블 정렬 (Bubble Sort)
이웃해 있는 두 값을 비교하고 위치를 교환하는 것을 반복하는 정렬 방법

동작 원리

인접한 두 원소를 비교하여 순서가 맞지 않으면 교환. 한 번 순회할 때마다 가장 큰 값이 맨 뒤로 이동

예: [5, 3, 1, 4, 2] → 5와 3 비교·교환 → [3, 5, 1, 4, 2] → 5와 1 비교·교환 → ...

④ 합병 정렬 (Merge Sort)
하나의 리스트를 정렬하기 위해 n개의 서브리스트로 분할하여 각각 정렬한 후, 정렬된 n개의 서브리스트를 서로 합병시키는 정렬 방법

동작 원리 (분할 정복)

리스트를 절반씩 분할 → 각 부분을 재귀적으로 정렬 → 정렬된 두 부분을 합병

예: [5,3,1,4,2] → [5,3] [1,4,2] → [3,5] [1,2,4] → [1,2,3,4,5]

⑤ 퀵 정렬 (Quick Sort)
기준 값(피벗)을 기준으로 작거나 같은 값을 지닌 데이터는 앞으로, 큰 값을 지닌 데이터는 뒤로 가도록 하는 정렬 방법

동작 원리

피벗 선택 → 피벗보다 작은 것은 왼쪽, 큰 것은 오른쪽으로 분리 → 각 부분에 재귀 적용

예: 피벗 3 → [1, 2, 3, 5, 4] → 왼쪽 [1,2], 오른쪽 [5,4] 각각 재귀

📊 5가지 정렬 알고리즘 한눈에 비교
알고리즘핵심 동작특징
선택 정렬최솟값을 선택하여 이동단순, 비효율적
삽입 정렬정렬된 부분의 적절한 위치에 삽입거의 정렬된 데이터에 효율적
버블 정렬인접한 두 값 비교·교환 반복구현 단순, 비효율적
합병 정렬분할 → 각각 정렬 → 합병분할 정복, 안정적
퀵 정렬피벗 기준으로 좌우 분리평균적으로 빠름
🔍 Ⅲ-2-3 탐색 알고리즘
🔎 탐색이란?
여러 개의 데이터 중에서 원하는 데이터 하나를 찾는 과정
📋 기본 탐색 알고리즘
① 순차 탐색 (Sequential Search)
나열된 데이터를 처음부터 차례대로 비교하며 원하는 데이터를 찾는 방법

특징

정렬 여부 무관. 데이터가 많을수록 느림. 구현 단순

예: [3, 7, 1, 9, 5]에서 9 탐색 → 3→7→1→9 순서로 비교

② 이진 탐색 (Binary Search)
나열된 데이터의 중앙에 있는 데이터를 기준으로 찾는 데이터가 왼쪽에 있는지 오른쪽에 있는지 판단하면서 탐색하는 방법

특징

반드시 정렬된 데이터에서만 사용 가능. 매 단계마다 탐색 범위가 절반씩 줄어들어 빠름

예: [1,3,5,7,9]에서 7 탐색 → 중앙 5 비교 → 오른쪽 [7,9] → 중앙 7 발견

🌳 트리/그래프 탐색 알고리즘
③ 너비 우선 탐색 (BFS: Breadth First Search)
데이터의 구조가 트리 혹은 그래프의 형태일 때, 시작 정점으로부터 가장 가까운 정점부터 탐색을 시작하는 방법

특징 · 동작

가까운 노드부터 넓게 퍼져나가며 탐색. 큐(Queue) 자료구조 활용

같은 레벨의 노드를 모두 탐색한 후 다음 레벨로 이동

④ 깊이 우선 탐색 (DFS: Depth First Search)
데이터의 구조가 트리 혹은 그래프의 형태일 때, 한 경로를 선택하여 끝 정점에 도달할 때까지 탐색을 진행하는 방법

특징 · 동작

하나의 경로를 끝까지 탐색한 후 다른 경로로 되돌아감. 스택(Stack) 자료구조 또는 재귀 활용

BFS vs DFS 비교

BFS가까운 노드 우선, 큐 사용
DFS깊은 경로 우선, 스택/재귀 사용

이진 탐색 주의사항

반드시 정렬된 데이터에서만 사용 가능. 순차 탐색은 정렬 불필요

📐 최단 경로 탐색 알고리즘
⑤ 다익스트라 (Dijkstra) 알고리즘
그래프의 한 정점에서 출발하여 다른 노드까지 이동하는 최소 비용을 가진 최단 경로를 탐색하는 알고리즘
한 정점을 탐색할 때마다 전체 경로를 갱신함
⑥ 벨먼-포드 (Bellman-Ford) 알고리즘
다익스트라 알고리즘과 같이 한 정점에서 다른 노드까지 최단 경로를 탐색하는 알고리즘
단, 음수 가중치와 경로, 사이클의 발생을 고려함

다익스트라 vs 벨먼-포드

  • 공통: 한 정점→다른 노드까지 최단 경로, 탐색마다 전체 경로 갱신
  • 차이: 벨먼-포드는 음수 가중치·음수 사이클 고려 가능

사용 상황

  • 음수 가중치 없을 때 → 다익스트라 (더 빠름)
  • 음수 가중치 있을 때 → 벨먼-포드
🌲 최소 신장 트리 탐색 알고리즘
⑦ 크루스칼 (Kruskal) 알고리즘
그래프를 구성하는 모든 간선에 대하여 가중치가 작은 순서대로 선택하여, 이미 선택된 간선과 정점과 비교했을 때 사이클이 발생하지 않도록 하는 방법
⑧ 프림 (Prim) 알고리즘
그래프를 구성하는 간선 중 최소 가중치를 가지는 간선을 선택하고, 선택된 간선과 연결된 노드와 연결된 다른 간선 중 최소 가중치를 가지는 간선을 선택하여 사이클이 발생하지 않도록 하는 방법

크루스칼 vs 프림 비교

  • 공통: 최소 신장 트리 생성, 사이클 방지
  • 크루스칼: 전체 간선 중 가중치 작은 것부터 선택
  • 프림: 이미 선택된 노드와 연결된 간선 중 최소 선택

최소 신장 트리 목적

그래프의 모든 노드를 연결하면서 간선의 가중치 합이 최소가 되는 트리 구성

📊 탐색 알고리즘 전체 정리
알고리즘적용 구조핵심 특징
순차 탐색배열/리스트처음부터 차례대로 비교, 정렬 불필요
이진 탐색정렬된 배열중앙값 기준 좌우 판단, 정렬 필수

구성 요소기능
텍스트 편집기프로그램 코드를 입력하고 수정하는 도구

디버거프로그램 코드를 테스트하고 오류를 발견하여 수정할 수 있도록 하는 도구
통합 개발 환경 (IDE): 프로그래밍 언어를 이용한 프로그램의 개발·번역·수정 등 전 과정에 걸쳐 도움을 주는 텍스트 편집기, 컴파일러, 디버거 등의 도구를 모두 포함하고 있는 프로그램 개발 환경

예약어 사용 불가if, for 등 파이썬 예약어(이미 역할이 지정된 단어)는 변수명으로 사용 불가

🗂️ Ⅲ-3-2 자료형 (Data Type)
📦 자료형이란?
변수에 저장될 데이터가 어떤 유형인지 구분하는 것
🔢 기본 자료형

수치형 (Numeric)

숫자 자료형

  • int 정수형 — 1, -3, 100
  • float 실수형 — 3.14, -0.5

불형 (bool)

참과 거짓을 나타내는 자료형

  • True 참
  • False 거짓

문자열 (str)

문자 자료형

  • 'hello' 또는 "hello"
  • +연산(이어붙이기), *연산(반복) 가능
문자열 상세
방법설명
기본 표현작은따옴표(' ') 또는 큰따옴표(" ")로 감싸서 표현
여러 줄 문자열따옴표를 세 개씩(''' 또는 """) 작성하거나 줄 끝에 백슬래시(\) 사용
주석으로 사용큰따옴표 세 개로 감싸진 경우("""...""") 주석으로 사용
특수 기호 출력세 개의 따옴표 또는 특수 기호 앞에 백슬래시(\) 활용
📋 시퀀스 자료형
순서가 있는 자료형으로, 순서대로 저장되고 저장되는 공간에 인덱스가 표시됨
종류: 문자열 ' ' 리스트 [ ] 튜플 ( )
인덱싱과 슬라이싱이 가능함

인덱싱 (Indexing)

시퀀스 자료형 데이터를 구성하는 각 데이터에 맨 앞(또는 맨 뒤)에서부터 순서대로 번호를 부여하는 것

앞에서: 0, 1, 2, ...  |  뒤에서: -1, -2, -3, ...

슬라이싱 (Slicing)

시퀀스 자료형 데이터를 구성하는 데이터의 사이에 맨 앞(또는 맨 뒤)에서부터 순서대로 번호를 부여하는 것

s[1:4] → 인덱스 1이상 4미만

📝 시퀀스 자료형 3가지: 문자열(' '), 리스트([ ]), 튜플(( )). 모두 인덱싱·슬라이싱 가능!
🧮 Ⅲ-3-3 연산자 (Operator)
⚙️ 연산자란?
특정한 작업을 수행하려고 사용하는 기호
어떤 값을 조작하거나 식을 계산
🔢 산술 연산자
수치형 데이터들을 대상으로 연산을 수행하는 연산자
연산자의미예시결과
+덧셈5 + 38
-뺄셈5 - 32
*곱셈5 * 315
/나눗셈5 / 31.666...
//몫5 // 31
%나머지5 % 32
**거듭제곱2 ** 38
⚖️ 비교 연산자
두 개 이상의 값이나 변수를 비교하여 True(참) 또는 False(거짓)을 판단하는 연산자

크기 비교

  • > 크다
  • < 작다
  • >= 크거나 같다
  • <= 작거나 같다

동등 비교

  • == 같다
  • != 같지 않다

주의!

= 는 대입(할당) 연산자

== 가 값이 같은지 비교하는 연산자

🧠 논리 연산자
논리식의 참과 거짓을 판단하는 연산자

and (논리곱)

두 조건이 모두 참일 때만 True

or (논리합)

두 조건 중 하나라도 참이면 True

not (논리 부정)

참 ↔ 거짓 반전

📊 연산자 우선순위
순위연산자설명
1위 (최고)( ) 괄호괄호 안의 연산식을 먼저 계산
2위** 거듭제곱곱셈·나눗셈보다 우선순위 높음
3위*, /, //, %곱셈·나눗셈·몫·나머지
4위+, -덧셈·뺄셈
5위>, <, >=, <=, ==, !=비교 연산자
6위 (최저)and, or, not논리 연산자
📝 우선순위 핵심: 산술 > 비교 > 논리 순서. 같은 우선순위 연산자는 왼쪽에서 오른쪽으로 계산!
⚠️ 거듭제곱(**)은 곱셈(*)보다 우선순위가 높다! 2 * 3 ** 2 = 2 * 9 = 18 (6**2 = 36이 아님)
📥📤 Ⅲ-3-4 표준 입출력 · 파일 입출력
📋 입출력의 종류

표준 입출력

키보드(표준 입력 장치)와 모니터(표준 출력 장치)를 이용하는 입출력

파일 입출력

파일 안의 데이터를 읽고 수정하고 저장하는 작업

⌨️ input() — 표준 입력
키보드로 데이터를 입력받는 명령어. 입력받은 값은 항상 문자열로 처리
특징설명
지시어 표시input("지시어") — 괄호 안에 지시어를 넣으면 실행 시 표시
값 저장변수 = input() — 입력된 값을 변수에 저장하여 사용
숫자 변환input()으로 받은 데이터는 문자열이므로 숫자 연산을 위해 int()로 형변환 필요
🖥️ print() — 표준 출력
모니터 화면에 데이터를 출력하는 명령어. 자동으로 커서가 줄바꿈(개행)됨
기능·옵션설명
콤마(,) 구분변수나 값을 콤마로 구분하여 입력하면 한 칸 띄어쓰기(공백)되어 출력
sep 옵션특정 문자열이나 이스케이프 문자로 구분하기 위해 sep 옵션 사용
end 옵션개행 위치에서 개행이 아닌 다른 출력을 원하는 경우 end 옵션 사용
포맷팅 (Formatting)
출력할 자료의 자료형을 지정하여 출력하는 것

① % 기호 이용

print("%d" % 값)

%d(정수), %f(실수), %s(문자열)

② format() 메소드

"{}" .format(값)

문자열 자료형의 format() 메소드 이용

③ f-string

f"{변수}"

가장 간결한 방식 (Python 3.6+)

📂 파일 입출력 — open()
파일 저장 변수 = open('파일 경로', '열기 모드')
데이터 저장 변수 = 파일 저장 변수명.readlines()
  → 데이터 저장 변수의 자료형은 배열(리스트)
열기 모드기능
r (읽기)파일을 읽기 전용으로 열기
w (쓰기)파일을 쓰기 전용으로 열기 (기존 내용 덮어쓰기)
a (추가)파일의 마지막에 새로운 내용 추가
s (모든 작업)모든 작업 가능
파일 객체 = open('파일 경로', '접근 방식')
데이터 저장 변수 = 파일 객체.read() 또는 readlines()
파일 객체.write("추가할 문자열", 추가할 데이터 변수명)
파일 객체.close()
