화학 결합과 물질의 세계
🌍 지각을 구성하는 규산염 광물
지각 구성 단계: 원소 → 광물 → 암석 → 지각
지각 원소 질량 비율 1위: 산소(O, 약 46%) → 2위: 규소(Si, 약 28%)
암석의 90% 이상: 규산염 광물
규산염 사면체 — 지각 광물의 기본 단위체

🔷 구조

규소(Si) 1개 + 산소(O) 4개 공유 결합

Si : O = 1 : 4

🔗 결합 방식

이웃한 사면체끼리 산소를 공유하며 연결

공유 산소 수에 따라 다양한 구조 형성

결합 구조에 따른 광물 종류
결합 구조광물특징
독립형감람석사면체 독립 존재, 깨짐
단사슬형휘석2방향 쪼개짐, 기둥 모양 결정

📝 다양한 광물이 존재하는 이유 = 규산염 사면체의 결합 구조가 다양하기 때문. 같은 단위체라도 연결 방식이 달라지면 완전히 다른 광물이 된다.

단백질 — 구조와 다양성
단위체: 아미노산 (약 20종류)
아미노산 → 펩타이드 결합 → 폴리펩타이드 → 꼬이고 접힘 → 단백질 (3차원 입체구조)
아미노산의 종류·수·결합 순서가 달라지면 다른 단백질이 만들어짐
📝 20종 아미노산 → 수만 종 단백질의 원리 = 한글 자음·모음 24개로 수천 개 단어를 만드는 원리와 동일. 배열 순서의 다양성이 핵심!
핵산 — DNA & RNA 비교
단위체: 뉴클레오타이드 = 인산 + 당 + 염기 (1:1:1)
구분DNARNA
구조이중나선 (두 가닥)단일 가닥
염기A, G, C, TA, G, C, U (타이민→유라실)
염기 결합A↔T, G↔C—
기능유전정보 저장유전정보 전달 (→라이보솜)
⚠️ DNA 상보적 염기 결합 규칙 — A는 반드시 T와, G는 반드시 C와 결합. 다양한 유전정보를 저장할 수 있는 이유는 뉴클레오타이드의 염기 결합 순서가 생물마다 다르기 때문이다.

🔵 도체

전류 잘 흐름
  • 자유 전자 많음
  • 전압 → 자유 전자 일정 방향 이동
  • 예: 철, 구리, 알루미늄

🔴 부도체

전류 안 흐름
  • 자유 전자 거의 없음
  • 전압 가해도 전류 흐르지 않음
  • 예: 고무, 유리, 나무

🟡 반도체

조건에 따라 다름
  • 도체·부도체의 중간
  • 조건에 따라 전류 조절 가능
  • 예: 규소(Si), 저마늄(Ge)
도핑 (Doping)
도핑: 순수한 반도체에 소량의 불순물을 첨가하여 전기 전도성을 높이는 것

원자가 전자 5개인 원소 첨가

여분의 전자 1개 생성 → 전자 이동 → 전류 흐름

예: 규소 + 인(P)

원자가 전자 3개인 원소 첨가

전자 빈자리(양공) 생성 → 전자 이동 → 전류 흐름

예: 규소 + 붕소(B)
