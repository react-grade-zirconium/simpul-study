📦3-6 다차원 데이터 구조
다차원 데이터 구조란?
데이터를 행과 열, 또는 여러 개의 차원으로 구성하여 저장하는 방법
많은 양의 데이터를 효율적으로 처리·관리하기 위해 사용
리스트는 순서가 있는 자료형 → 같은 데이터를 같은 순서로 저장해야 같은 리스트로 판단
① 1차원 리스트
가장 기본적으로 데이터를 묶어 하나의 이름으로 관리하는 방법
리스트를 구성하는 각각의 값 → 요소(원소)
저장된 요소의 위치 정보 → 인덱스 (0부터 시작)

요소(원소)

리스트를 구성하는 각각의 값

같은 자료형 또는 서로 다른 자료형 모두 가능

인덱스

저장된 요소의 위치 정보

0부터 시작, 음수 인덱스도 사용 가능 (-1은 마지막)

인덱싱 / 슬라이싱

list[i] → 인덱싱

list[a:b] → 슬라이싱 (a이상 b미만)

# 1차원 리스트 선언 a = [1, 2, 3, 4, 5] # 정수형 요소 b = ['apple', 'banana', 'cherry'] # 문자열 요소 c = [] # 빈 리스트 # 인덱싱 print(a[0]) # 1 (첫 번째 요소) print(a[-1]) # 5 (마지막 요소) # 슬라이싱 print(a[1:4]) # [2, 3, 4]
② 리스트 메소드
📝 메소드: 리스트를 조작(삽입·삭제·수정)하기 위해 활용. 리스트.메소드() 형태로 작성
메소드기능예시
append(x)리스트 맨 뒤에 요소 x 추가a.append(6)
insert(i, x)인덱스 i 위치에 요소 x 삽입a.insert(2, 99)
remove(x)첫 번째로 나오는 요소 x 삭제a.remove(3)
pop(i)인덱스 i의 요소를 꺼내고 삭제 (기본: 마지막)a.pop()
sort()리스트를 오름차순 정렬 (reverse=True면 내림차순)a.sort()
reverse()리스트 순서를 거꾸로 뒤집음a.reverse()
extend(list)리스트 뒤에 또 다른 리스트를 이어 붙임 (+연산과 동일)a.extend([7,8])
clear()리스트의 모든 데이터를 삭제하고 빈 리스트로 만듦a.clear()
index(x)요소 x를 오름차순 탐색하여 위치 인덱스 반환a.index(3)
💡 형변환: 다른 시퀀스 자료형을 list()로 리스트로 변환 가능. 순서 없는 자료형(예: set)은 변환 시 순서가 무작위로 부여됨
③ 2차원 리스트
1차원 리스트가 겹쳐서 쌓인 구조 — 가로축(행)과 세로축(열)의 두 가지 인덱스로 값에 접근
접근 방법: 리스트[행 인덱스][열 인덱스]
# 2차원 리스트 선언 (3행 3열) matrix = [ [1, 2, 3], [4, 5, 6], [7, 8, 9] ] print(matrix[0][0]) # 1 (0행 0열) print(matrix[1][2]) # 6 (1행 2열) print(matrix[2][1]) # 8 (2행 1열)
🔀4-1 조건문
조건식이란?
비교 연산자와 논리 연산자를 활용해 작성하며, 결과는 참(True) 또는 거짓(False)
조건문을 통해 결과에 따라 동작을 제어함

비교 연산자

  • == 같다  |  != 다르다
  • > 크다  |  < 작다
  • >= 크거나 같다  |  <= 작거나 같다

논리 연산자

  • and : 두 조건 모두 참일 때 True
  • or  : 하나라도 참이면 True
  • not : 참↔거짓 반전
① if문 (단순 조건문)
가장 단순한 형태의 조건문. 조건식이 참(True)일 때만 특정 명령문을 실행
if 조건식: 실행할 명령문 # 조건이 참일 때만 실행 (들여쓰기 필수!) # 예시 score = 85 if score >= 80: print("합격")
② if-else문 (이중 조건문)
조건식이 참일 때와 거짓일 때 실행하는 명령문이 다른 구조
if 조건식: 참일 때 실행할 명령문 else: 거짓일 때 실행할 명령문 # 예시 score = 55 if score >= 60: print("합격") else: print("불합격")
③ 중첩 if문
조건문 안에 또 다른 조건문을 포함하는 구조
if 조건식1: if 조건식2: # 조건식1이 참일 때 조건식2 판별 명령문 A else: 명령문 B else: 명령문 C
④ if-elif-else문 (다중 조건문)
선택 사항이 여러 개일 경우 사용. 여러 개의 조건식에 따라 명령을 다르게 실행
if 조건식1: 명령문1 elif 조건식2: 명령문2 elif 조건식3: 명령문3 else: 명령문4 # 위 조건 모두 거짓일 때 # 예시: 학점 계산 score = 75 if score >= 90: print("A") elif score >= 80: print("B") elif score >= 70: print("C") else: print("F")
조건문 종류구조사용 상황
ifif만참일 때만 실행
if-elseif + else참/거짓 2가지 분기
중첩 ifif 안에 if조건이 계층적일 때
if-elif-elseif + elif(들) + else3가지 이상 분기
🔁4-2 반복문
특정 명령문을 반복해서 실행해야 할 때 사용하는 명령문
반복할 명령을 계속 똑같이 기술해야 하는 비효율성 개선
종류: for문, while문
① for문
시퀀스(리스트, 문자열, range 등)의 요소를 순서대로 꺼내며 반복
for 변수 in 시퀀스: 반복할 명령문 # range() 사용 for i in range(5): # 0,1,2,3,4 print(i) for i in range(1, 6): # 1,2,3,4,5 print(i) for i in range(0, 10, 2): # 0,2,4,6,8 (2씩 증가) print(i) # 리스트 순회 fruits = ['apple', 'banana', 'cherry'] for f in fruits: print(f)
② while문
조건식이 참(True)인 동안 계속 반복. 조건이 거짓이 되면 반복 종료
while 조건식: 반복할 명령문 # 조건을 변화시키는 코드가 없으면 무한루프! # 예시 i = 1 while i <= 5: print(i) i += 1 # i = i + 1 (조건 변화 필수!)
③ break / continue

⛔ break

강제로 반복문을 벗어남

중첩 반복문의 경우 가장 가까운(break가 포함된) 반복문만 벗어남

⏩ continue

특정 명령문을 건너뛰고 반복문의 처음으로 돌아가서 계속 실행

# break 예시: 3을 만나면 종료 for i in range(1, 6): if i == 3: break print(i) # 1, 2 출력 후 종료 # continue 예시: 3을 건너뜀 for i in range(1, 6): if i == 3: continue print(i) # 1, 2, 4, 5 출력
구분for문while문
반복 기준시퀀스의 요소를 순서대로조건식이 참인 동안
반복 횟수시퀀스 길이만큼 (정해짐)조건에 따라 달라짐
무한루프일반적으로 발생 안 함조건 미변화 시 무한루프
주요 사용리스트/range 순회조건 기반 반복

# 함수 정의 (def 키워드 사용) def 함수명(매개변수1, 매개변수2): 실행할 명령문 return 반환값 # 반환값이 없으면 생략 가능 # 함수 호출 함수명(인수1, 인수2) # 예시: 두 수의 합 def add(a, b): return a + b result = add(3, 5) # result = 8 print(result)
매개변수 / 인수 / 반환값

매개변수 (Parameter)

함수 정의 부분의 괄호 안에 작성

함수 호출 시 보내는 값

함수 호출 부분의 괄호 안에 작성

반환값 (Return Value)

함수의 결과를 호출한 곳으로 전달하는 값

return문 사용

지역 변수 vs 전역 변수

지역 변수 (Local Variable)

함수와 같은 특정 지역에서만 사용하는 변수

함수 밖에서는 접근 불가

전역 변수 (Global Variable)

함수 외부에 생성되어 프로그램 전체에서 사용하는 변수

함수 안에서 수정하려면 global 키워드 필요

x = 10 # 전역 변수 def func(): y = 20 # 지역 변수 (함수 안에서만 사용 가능) print(x) # 전역 변수는 읽기 가능 print(y) func() # print(y) → 오류! 지역 변수는 함수 밖에서 접근 불가

📊빅데이터 개념과 분석
① 빅데이터란?
디지털 환경에서 생성된 대규모 데이터
다양한 유형의 대규모 데이터를 데이터 과학 기술로 가치를 추출하여 활용하는 포괄적 개념
정형 데이터(고정된 형식과 구조에 맞게 저장된 데이터) ↔ 비정형 데이터(고정된 구조나 형태가 없는 데이터)로 구분

② 데이터 수집하기
분석에 필요한 데이터 수집
고려 사항: 데이터 양의 균형, 개인정보 노출, 데이터 편향성, 저작권
수집 방법: 자동화된 수집기, 인터넷 직접 검색, 직접 수집(설문조사·실험관찰)
수집 방법내용
인터넷 직접 검색공공 데이터 포털, 국가 통계 포털, 캐글, 데이콘, 지표누리 등의 빅데이터 공유 자료 사용
수집 프로그램로그 수집기, 크롤링, 오픈소스 데이터 수집기 등 사용
참고 자료각종 언론 자료, 논문 및 서적 내용 참고
③ 데이터 분석 — 전처리
수집된 데이터를 전체적으로 살펴보고, 분석에 적합한 형태로 데이터를 가공하는 과정

통계 지표 확인

  • 평균: 모든 데이터를 더해 개수로 나눈 값
  • 중앙값: 순서대로 나열했을 때 정가운데 값
  • 최빈값: 가장 자주 나타난 값

데이터 이상치 처리

  • 결측치: 누락된 값
  • 중복값: 중복된 값
  • 이상치: 분포 범위에서 크게 벗어난 값

처리 방법

결측치·중복값·이상치를 찾아 제거하거나 분석에 적합한 형태로 가공

④ 데이터 시각화
데이터를 명확하고 효과적으로 전달하기 위해 색채·도형·이미지 등을 이용하여 시각적으로 표현
데이터 간의 흐름과 관계를 해석하고 패턴을 찾아 분석
시각화 유형목적주요 차트
시간 시각화시간에 따라 변하는 데이터의 추이 표현선그래프, 막대그래프, 영역형 차트
