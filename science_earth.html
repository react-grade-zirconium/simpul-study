📌 III. 시스템과 상호작용 › 01 지구시스템의 구성 요소

🌐 시스템이란? — 지구는 왜 시스템인가

시스템(system): 여러 구성 요소가 함께 작동하며 서로 영향을 미치는 것.
자동차(엔진·변속기·바퀴·제동 장치)처럼 하나에 문제가 생기면 다른 부분에도 영향을 준다.

지구도 마찬가지로 지권·기권·수권·생물권 네 권역이 서로 물질과 에너지를 교환하며 하나의 시스템을 이룬다.

☀️ 태양계가 지구에 미치는 영향

태양계에서 가장 큰 영향을 미치는 천체는 태양이다. 지구는 태양에서 너무 멀지도 가깝지도 않아 액체 상태의 물이 존재하고 생명이 살 수 있다.
🌞 태양 에너지
  • 낮과 밤의 교대 → 시간의 흐름
  • 다양한 기상 현상(구름·비·바람) 유발
  • 식물의 광합성 에너지원
  • 지구시스템 에너지의 가장 큰 원천
🌙 달 · 태양의 인력
  • 조석력(밀물·썰물) 발생
  • 우리나라 서해안의 넓은 갯벌 형성
  • 현재 지구 모습도 태양·달과의 상호작용 결과
🔑 핵심 암기: 지구가 액체 상태의 물을 갖는 이유 = 태양과 '적당한 거리'에 있기 때문!

🔵 지구시스템의 4대 권역

지구시스템은 지권 · 기권 · 수권 · 생물권 네 권역으로 구성되며, 권역 사이에서 물질과 에너지가 이동하며 다양한 자연 현상이 일어난다.
① 기권 (Atmosphere)
지구 표면을 둘러싼 공기의 층. 높이에 따른 기온 변화로 대류권 → 성층권 → 중간권 → 열권으로 구분.
층고도 (km)기온 변화특징
대류권0~약 11올라갈수록 낮아짐기상 현상 발생, 대류 활발
성층권약 11~50올라갈수록 높아짐오존층 존재 → 자외선 차단
중간권약 50~80올라갈수록 낮아짐유성(별똥별) 현상
열권약 80~올라갈수록 높아짐오로라 발생, 우주 공간과 맞닿음
기권의 역할: ① 호흡할 공기 제공 ② 유성체·자외선 차단(생명체 보호) ③ 온실효과 → 지표 온도 유지
② 수권 (Hydrosphere)
지구에 있는 모든 물. 대부분(약 97.5%)은 해수로 존재. 해수 깊이에 따라 혼합층 → 수온약층 → 심해층으로 구분.
층특징
혼합층바람의 혼합으로 수온 일정, 태양 에너지 흡수
수온약층깊어질수록 수온 급감 → 혼합층·심해층 구분짓는 경계
심해층수온 낮고 일정, 태양광 거의 도달 안 함

수권의 역할: 기권과 상호작용하며 기상 현상 일으킴, 막대한 태양 에너지 저장 → 지구 기온 일정 유지, 생명체 환경 제공

③ 지권 (Geosphere)
지구의 딱딱한 표면과 내부. 지표에서부터 지각 → 맨틀 → 외핵 → 내핵 층상 구조.
층깊이특징
지각지표~약 30km대륙 지각(두꺼움) / 해양 지각(얇음)
맨틀~약 2900km지구 부피의 대부분, 열 대류 → 판 이동
외핵~약 5100km액체 상태, 지구 자기장 생성
내핵~약 6400km고체 상태, 고온·고압

맨틀과 지각은 서로 영향을 주고받으며 화산 활동, 지진, 지형 변화를 일으킨다.

④ 생물권 (Biosphere)
인간을 포함하여 지구에 사는 모든 생물. 지권·수권·기권 속에 다양한 생태계를 이루며 분포.

생물권의 역할: 환경 변화에 반응(적응·도태), 광합성과 호흡으로 기권의 조성 변화, 식물 뿌리 → 지권의 단단한 암석을 풍화시키는 등 다른 권역에 영향.

🔄 권역 간 상호작용 예시

현상관련 권역설명
태풍기권 ↔ 수권따뜻한 해수(수권)가 기권 에너지 공급 → 태풍 발생
밀물·썰물수권 ↔ (달·태양 인력)달·태양의 인력으로 해수면 높이 변화 → 갯벌 형성
광합성생물권 ↔ 기권·수권CO₂ 흡수·O₂ 방출, 물 흡수·분해
화산 분출지권 → 기권·수권용암·화산재 방출, 기온 변화, 해수 성분 변화
암석 풍화생물권 ↔ 지권식물 뿌리가 암석 균열 → 토양 형성
🔑 외권(기권 바깥 우주)에서 오는 태양 에너지는 지구 생명체와 자연 현상 대부분의 근원!
📌 III. 시스템과 상호작용 › 02 지구시스템의 물질 순환과 에너지 흐름

⚡ 지구시스템의 에너지원

지구에서 발생하는 자연 현상에는 에너지가 필요하다. 에너지원은 크게 세 가지이다.
① 태양 에너지

에너지원 중 가장 큰 비중을 차지. 기상 현상, 물의 순환, 생물의 광합성 등 대부분의 자연 현상을 일으킴.

② 지구 내부 에너지

지구 내부에서 나오는 에너지. 맨틀 대류 → 판 이동 → 화산 활동·지진 발생.

③ 조력 에너지

태양과 달의 인력으로 생기는 밀물·썰물. 세 에너지원 중 차지하는 비중이 가장 작음.

⚠️ 시험 포인트: 지구시스템 에너지원 중 가장 큰 것 = 태양 에너지, 화산·지진의 에너지원 = 지구 내부 에너지

💧 물의 순환

물은 고체(얼음) → 액체(물) → 기체(수증기)로 상태를 바꾸면서 지구시스템의 여러 권역을 순환한다. 순환의 원동력은 태양 에너지이다.

♻️ 탄소의 순환

탄소는 생명체를 구성하는 탄소 화합물의 중심 원소로, 기권·수권·지권·생물권을 다양한 형태로 순환한다.
기권의 탄소

CO₂(이산화탄소) 형태로 존재. 대기 중 CO₂ 농도 상승 → 온실 효과 강화.

수권의 탄소

H₂O + CO₂ 반응으로 탄산 이온(HCO₃⁻, CO₃²⁻) 형태 존재. 해양 생물이 이를 이용해 탄산칼슘(껍데기) 형성.

지권의 탄소

Ca²⁺, Mg²⁺, K⁺, Na⁺ 이온과 결합한 탄산 광물(석회암), 화석 연료(석탄·석유)로 저장.

생물권의 탄소

광합성으로 CO₂ 흡수 → 유기물 생성. 호흡·분해로 다시 CO₂ 방출. 생물의 사체 → 지권에 화석 연료로 저장.

탄소 순환 경로 정리
이동 방향과정에너지
기권 → 생물권식물의 광합성 (CO₂ 흡수)태양 에너지 흡수
생물권 → 기권생물 호흡, 유기물 분해에너지 방출
기권 → 수권CO₂ 해수에 용해—
수권 → 지권탄산칼슘 침전 → 석회암—
지권 → 기권화산 분출 (CO₂ 방출)지구 내부 에너지 방출
지권 → 기권화석 연료 연소에너지 방출
⚠️ 현대 문제: 화석 연료 연소 → 대기 중 CO₂ 급증 → 온실 효과 강화 → 지구 평균 기온 상승 → 해수 산성화. 지구시스템 균형이 깨지지 않도록 책임감을 가져야 한다.

🔥 에너지 흐름과 물질 순환의 관계

핵심 원리

탄소가 순환하는 과정에서 에너지 흐름이 일어난다.

  • 식물이 광합성을 할 때 → 태양 에너지 흡수
  • 지권의 화석 연료가 연소할 때 → 에너지 방출
  • 이 에너지가 태양 에너지로부터 비롯되며, 물질 순환 시 에너지가 흡수되거나 방출됨
📌 III. 시스템과 상호작용 › 03 지권의 변화와 판 구조론

🌋 화산 활동과 지진

🌋 화산 활동

지하의 마그마가 지표로 분출하는 현상. 화산이 폭발하면 용암·화산재가 분출되고, 때로는 지진 발생. 에너지원: 지구 내부 에너지

🏚️ 지진

지각 일부가 끊어지면서 땅이 흔들리는 현상. 발생 시간은 짧지만 엄청난 에너지 방출. 해저에서 발생 시 지진 해일(쓰나미) 유발.

화산·지진은 전 세계에 고르게 분포하지 않고 특정 지역(대륙 주변부)에 집중 → 판의 경계와 일치!

🔥 지구 내부 에너지와 맨틀 대류

지구 중심부 온도는 약 6000 ℃로 태양 표면과 비슷하다. 지구 내부에서 방출되는 열에너지가 지구 전체 에너지이다.

맨틀 대류: 지구 내부의 열이 맨틀을 부분적으로 녹여 유동성을 갖게 함. 뜨거운 맨틀 물질이 상승하고 식으면 다시 가라앉는 대류 운동이 지속됨.

→ 이 대류가 판(plate)을 움직이는 원동력!

🗺️ 판 구조론

판(plate): 지각과 맨틀 상부를 포함하는 두꺼운 층(두께 약 100 km)의 단단한 암석층.
지구 표면은 약 10여 개의 주요 판과 여러 작은 판으로 이루어짐.
해양판

해양 지각을 포함. 밀도가 크고 얇음. 대륙판과 충돌 시 밀도 차이로 아래로 들어감(섭입).

대륙판

대륙 지각을 포함. 밀도가 작고 두꺼움. 해양판과 충돌 시 위에 올라타 산맥 형성.

🔑 주요 판 이름: 태평양판·북아메리카판·유라시아판·아프리카판·남아메리카판·인도판·오스트레일리아판·남극판·코코스판·카리브판·나스카판·필리핀판 등

🌐 지권 변화가 지구시스템에 미치는 영향

지권 변화영향받는 권역현상
화산 분출기권화산재가 태양빛 차단 → 일시적 기온 하강
화산 분출수권해수 성분 변화, 지진 해일 발생
화산 분출생물권생물 서식지 파괴, 새로운 섬·화산섬 생성
지진수권해저 지진 → 지진 해일(쓰나미)
지진·화산생물권생물의 생존과 삶의 터전에 영향
화산 분출지권↔수권지구 물질과 에너지가 수권으로 이동
지권의 변화는 단순히 땅만 변화시키는 것이 아니라 지구시스템 전체의 상호작용을 통해 다른 권역에도 영향을 준다.
📌 III. 시스템과 상호작용 › 03 지권의 변화와 판 구조론 (판 경계)

🧩 판의 경계 3종류

인접한 두 판은 서로 멀어지거나, 충돌·부딪히거나, 스쳐 지나가는 방식으로 움직인다. 판의 경계에서 지진·화산 활동이 집중된다.

① 보존형 경계 (Transform)

  • 두 판이 서로 스쳐 지나가는 경계
  • 판이 생성·소멸되지 않음
  • 지진 자주 발생
  • 마그마 상승 없어 화산 활동 거의 없음
  • 예: 산안드레아스 단층 (태평양판 ↔ 북아메리카판)

② 발산형 경계 (Divergent)

  • 두 판이 서로 멀어지는 경계
  • 맨틀이 상승하며 양옆으로 이동 → 새로운 지각 생성
  • 화산 활동 활발, 지진 발생
  • 예: 동아프리카 열곡대, 대서양 중앙 해령

③ 수렴형 경계 (Convergent)

  • 두 판이 서로 가까워지며 충돌하는 경계
  • 해양판 + 대륙판: 섭입 → 해구, 호상열도
  • 대륙판 + 대륙판: 충돌 → 습곡산맥
  • 화산 활동, 지진 자주 발생
  • 예: 히말라야 산맥 (인도판 ↔ 유라시아판)

🏔️ 판의 운동으로 생긴 지형

지형경계 유형형성 과정예시
습곡산맥수렴형 (충돌형)밀도 비슷한 두 대륙판이 충돌 → 지층이 솟아올라 높은 산맥히말라야 산맥
해구수렴형 (섭입형)해양판이 대륙판 밑으로 들어가 → 깊은 바다 골짜기마리아나 해구
호상열도수렴형 (섭입형)섭입 경계에서 마그마 상승 → 활화산이 한 줄로 늘어선 화산섬 열일본 열도
열곡대발산형두 판이 갈라지며 마그마 상승 → 새 지각 생성, 새 지형 탄생동아프리카 열곡대
해령발산형해저에서 마그마 분출 → 수중 산맥(해령) 형성대서양 중앙 해령
단층보존형판이 스쳐 지나가며 어긋난 지층산안드레아스 단층
섭입형 수렴 경계 상세
해양판 + 대륙판 충돌 시
  • 밀도가 큰 해양판이 밀도가 작은 대륙판 아래로 섭입(subduction)
  • 섭입대 주변에 해구 형성 (가장 깊은 바다)
  • 섭입되는 해양판에서 마그마 생성 → 대륙판 위에 화산 활동·지진
  • 화산이 바다 위로 나타나면 호상열도
대륙판 + 대륙판 충돌 시 (충돌형)
  • 밀도가 비슷해 한쪽이 섭입되지 않고 충돌·솟아오름
  • 거대한 습곡산맥 형성 (히말라야, 알프스)
  • 화산 활동 거의 없음, 지진은 발생

🌍 판 경계 지형 세계 사례

지역판 경계 유형특징 지형
히말라야 산맥수렴형(충돌형)인도판 + 유라시아판 → 세계 최고 습곡산맥
일본 열도수렴형(섭입형)해양판 섭입 → 호상열도, 지진·화산 매우 잦음
동아프리카 열곡대발산형아프리카판 분열 중, 마그마 상승·새 지각 생성
아이슬란드발산형대서양 중앙 해령이 지표에 드러남, 화산 활동 활발
산안드레아스 단층보존형태평양판 ↔ 북아메리카판 스쳐 지나감, 샌프란시스코 지진 잦음
마리아나 해구수렴형(섭입형)태평양판 + 필리핀판 섭입 → 세계 최심부
🔑 아이슬란드는 발산형 경계(대서양 중앙 해령)에 위치 → 온천이 많고 화산 활동 활발. 두 판이 서로 다른 방향으로 이동해 갈라지는 곳!
