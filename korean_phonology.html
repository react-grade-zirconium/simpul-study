🔤음운이란?
음운: 말의 뜻을 구별해 주는 소리의 가장 작은 단위

분절 음운 (음소)

  • 자음: 발음 기관의 공기 방해 있음(有)
  • 모음: 발음 기관의 공기 방해 없음(無)

비분절 음운 (운소)

소리의 길이, 높이, 세기, 억양 등

[말:]→馬(말), [말:ː]→言(말씀) — 길이로 의미 구별

최소 대립쌍

하나의 음운만 다른 단어의 쌍

예) '말/발', '남/님', '산/간', '불/풀', '살/쌀'

최소 대립

최소 대립쌍에서 서로 다른 음운

예) 'ㅁ/ㅂ', 'ㅏ/ㅣ', 'ㅅ/ㅆ', 'ㅂ/ㅍ', 'ㄴ/ㄱ'

합성어 vs 파생어 처리 차이

합성어 — ㄴ 첨가만

솜이불 → [솜니불]

두 실질 형태소가 결합. 바로 ㄴ 첨가 적용.

홑이불 → [홑이불] → [혼이불] → [혼니불] → [혼니불]

🧩 형태소와 단어 (자투리 개념)
①형태소의 분류
형태소: 뜻을 가진 가장 작은 말의 단위

의미 유무에 따른 분류

  • 실질 형태소: 의미 有 (실질적 의미를 지님)
  • 형식 형태소: 의미 無, 문법적 기능만 → 조사 어미 접사

자립성에 따른 분류

  • 자립 형태소: 혼자 쓰임
  • 의존 형태소: 혼자 쓰이지 않음 (= 형식 형태소 + 어근)
예문 분석: "철수가 밥을 먹었다"
형태소분류설명
철수자립, 실질명사 — 혼자 쓰이고 실질적 의미 있음
가의존, 형식주격 조사
밥자립, 실질명사
을의존, 형식목적격 조사
먹-의존, 실질어간(어근) — 실질적 의미를 가지나 혼자 쓰이지 못함
-었-의존, 형식과거 시제 선어말 어미
-다의존, 형식어말 어미 (종결형)
📌 '먹었다'에서 '먹-'은 의존+실질(어근), '-었-'·'-다'는 의존+형식(어미). 조사('가','을')도 의존+형식.

④어간 / 어미 / 어근 / 접사

어간 (語幹)

활용할 때 변화하지 않는 부분
= 어근 + 접사(접두사/접미사)

어미 (語尾)

활용할 때 변화하는 부분 (어말 어미·선어말 어미)

어근 (語根)

단어의 실질적 의미를 나타내는 핵심 부분

접사 (接辭)

접두사(어근 앞) / 접미사(어근 뒤) — 의미 추가 또는 품사 바꿈

예시: "치솟다"
구성 요소분류설명
치-접사 (접두사)'위로'의 뜻을 더함
솟-어근실질적 의미('솟다')
치솟-어간 (접사+어근)활용 시 변화하지 않음
-다어미활용 시 변화함 (다→고→니→자 등)
💡 용언에서 접사가 없을 때는 어간 = 어근이 된다.
예) '먹다' → 어간 '먹-' = 어근 '먹-' (접사 없음)
