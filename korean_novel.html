서사 갈래의 이해 소설의 형식적 특징
📚Ⅰ. 서사 갈래란?
현실에서 실제로 일어날 법한 이야기를 허구적 인물과 사건을 통해 형상화한 문학 양식
하위 장르: 설화 → 고전소설 → 신소설 → 현대소설
소재 — 인간의 세 가지 괴로움

① 불완전한 사회 구조

생존 경쟁이나 억압적 체제의 모순에서 오는 괴로움

② 인간의 욕망

사랑·성공·우월감 등에 집착하고, 이루지 못하거나 이루기 위해 경쟁하는 데서 오는 괴로움

③ 삶의 근원적 괴로움

변화(무상함)와 죽음(유한성) — '나' 또한 사라져야 한다는 근원적 고독과 슬픔

허구적 인물과 개연성
이야기가 그럴 듯하게 진행되려면 특정 공간 + 특정 시간이 설정되어야 하며,
갈등과 사건을 일으키는 인물도 그럴 듯하게 만들어야 함
→ 허구적 사실이지만 개연성이 반드시 있어야 함
📌 개연성: 사건의 인과가 앞뒤로 맞고, 독자가 받아들일 수 있는 설정과 행동 흐름이 유지되는 정도.
우연에 의해 사건이 전개될수록 현대소설보다 고전소설에 가까워짐.

인물의 성격 제시 방법

간접 제시 (보여주기) = 극적 제시

인물의 외양 묘사·행동·대화 등을 통해 가치관·심리를 독자가 짐작하도록 하는 방식

직접 제시 (말해주기) = 요약적 제시

서술자가 인물의 가치관·심리·과거 행적을 직접 요약하여 설명. 때로 평가도 내림

갈등
욕망의 충돌, 또는 등장인물과 환경 사이의 모순과 대립으로 일어나는 문제

내적 갈등

한 인물의 마음속에서 일어나는 심리적 갈등

외적 갈등

인물과 인물 / 인물과 사회 / 인물과 자연 / 인물과 운명

유형설명
인물 ↔ 인물주동·반동 인물 사이의 가치관·태도·감정·환경 등의 차이로 발생
인물 ↔ 사회개인이 속한 사회의 윤리나 제도 등과 충돌하여 발생
인물 ↔ 자연거대한 힘을 지닌 자연환경과 부딪쳐 싸우면서 겪는 갈등
인물 ↔ 운명주어진 운명을 벗어나지 못하는 데에서 오는 갈등
사건과 배경

사건

배경

  • 작품의 주제 부각

구성 방식의 종류
1단일 구성 / 복합 구성
단일: 하나의 이야기 줄기 / 복합: 여러 이야기 줄기가 얽히는 구성
2순행적 / 역순행적 시간 구성
순행적: 시간 흐름대로 서술 / 역순행적: 현재에서 과거로 거슬러 올라가거나 시간을 뒤섞어 서술
3액자식 구성
외부 이야기(외화) 안에 내부 이야기(내화)가 들어 있는 이야기 속 이야기 구조
외화 서술자 ≠ 내화 서술자임에 주의
4병렬식 구성
동시대 다른 공간에서 일어나는 사건을 A–B–A'–B' 형태로 교차하여 서술
5의식의 흐름 기법
이어지는 의식과 생각의 흐름을 인위적인 장치 없이 그대로 기술하는 기법
6연작식 구성 (피카레스크식)
동일 인물들이 동일 배경으로 한, 독립적인 여러 에피소드가 연속되는 방식
예) 명탐정 코난 — 동일 인물·배경, 수백 권의 독립 에피소드
7옴니버스식 구성
전혀 다른 인물·배경의 각각의 이야기를 묶어 놓은 방식. 단, 주제의식은 동일해야 함
예) 봉산탈춤, 나미야 잡화점의 기적
8여로형 구성
인물이 여행길을 다니면서 발생하는 사건과 해결로 이루어지는 구성
예) 전설의 고장, 창화촌, 구마호 등
👁️Ⅳ. 소설의 시점
서술자: 작품 안이나 밖에서 작품 내용과 독자 사이에 개입하여 이야기를 이끌어 가는 화자
소설은 기본적으로 시제가 과거형 — 서술자가 이미 알고 있는 이야기를 독자에게 전달하는 개념
소설 속 인물의 말은 대체로 큰따옴표("")로 인용됨
1인칭 주인공 시점 나 = 주인공

소설 속 주인공인 '나'가 자신의 이야기를 전개. 인물의 내면 심리를 효과적으로 전달하고 독자에게 친근감과 신뢰감을 줌. 주관적이며 다른 인물의 심리를 들여다볼 수 없음.

1인칭 관찰자 시점 나 = 주변 인물

소설 속 주변 인물인 '나'가 주인공의 이야기를 전개. 주인공의 내면을 직접 드러내지 않아 긴장감과 신비감을 줌. 독자가 서술 내용을 근거로 직접 추측하게 함.

3인칭 전지적 작가 시점 서술자 = 전지전능

소설 밖의 서술자가 인물과 사건 전개를 모두 알고 이야기를 전달. 작가의 사상과 인생관이 직접 드러남. 독자의 상상적 참여가 제한될 수 있음.

3인칭 작가 관찰자 시점 객관적 관찰

소설 밖의 서술자가 객관적 태도로 관찰한 사실만 전달. 서술자가 일체의 해석이나 평가를 내리지 않아 독자가 상상력을 발휘하도록 함.

3인칭 제한적 전지적 작가 시점 선택적 작가 시점 / 초점화자

서술자가 한 인물에만 초점을 두고 그의 내면을 상세히 묘사. 다른 인물들은 그 인물의 시각에서 관찰된 내용만 서술됨.

📝 출제 형태: "특정 인물의 시각에서 사건과 인물을 바라보고 그 내면을 효과적으로 드러내고 있다."

서술자의 개입
서술자가 작품 속에 등장해서 본인의 입으로 인물 혹은 상황에 대한 평가를 직접 하는 것
예) "쫓겨 가는 운명이거늘 어디를 간들 신선하랴."
